# 夏夏的生日小街

为夏夏 2026 年 10 月 18 日的 22 岁生日准备的静态网站。

## 本地浏览

双击同目录的 `夏夏的生日小街.html` 可以离线打开完整网站，包括插画、互动、生日卡和声音。这个文件由 `node scripts/export-offline.mjs` 从正式源码生成，修改源码后重新运行此命令即可更新。

`给夏夏的生日信.txt` 是网页内生日信的纯文字版，可以用于誊写手写信。压缩包同时包含离线网站、文字信件和本说明。

在当前目录运行 `npm run dev`，打开 `http://127.0.0.1:4173`。直接打开 `dist/index.html` 也可浏览主要内容。

## 内容与功能

- 点击桂花糕或前排鲜花饼，可拿起、靠近轻咬、停留后放回，留下真实缺口；后排鲜花饼和盘子留在原位
- 再点可继续尝，三口后下一次会补上新的一份；碎屑与轻咬音效在咬下时出现，插画与文字按钮均可操作
- 可反复播放的落章、墨色波纹与两种甜点各自的品鉴记录；短音效遵循现有声音开关
- 三张沿途小记
- 手机离开街口后显示“小街／许愿／来信”快捷入口，弹窗打开时收起
- 可刮开或直接揭开的生日好运签
- 蛋糕下方的按钮可熄灭蜡烛并播放轻量庆祝，操作时能同时看见火焰
- 仅在当前页面内保留的愿望，不发送、不记录到服务器
- 在浏览器本地生成 PNG 生日卡；默认不含愿望，可自行勾选加入
- 可拆开的生日保证书，以及完整信件长图预览与保存入口
- 主动开启的原创合成轻音乐，无外部音频依赖

所有功能均在浏览器中运行，没有统计、账户、聊天记录导入或后台数据收集。未经访问者操作不播放声音。系统减少动态效果偏好会被尊重。

本轮已检查 320、390、768、1280 像素宽度、键盘揭签、图片弹窗关闭后的焦点恢复、120 字愿望排版，以及信件长图预览。浏览器拒绝了自动化下载测试，实际下载落盘这一步尚未验证。

## 插画

首页水彩街景由内置图像生成工具生成，正式资产位于 `dist/assets/street-watercolor.png`，完整提示词保留在 `work/art-direction.txt`。其余四幅插画为项目自有 SVG。

## GitHub Pages

网页源文件在 `dist/`。`.github/workflows/pages.yml` 会在 `main` 分支更新后检查网站，并将 `dist/` 发布到 GitHub Pages。

首次部署时，将仓库的 **Settings → Pages → Source** 设为 **GitHub Actions**。发布成功后的网址可在 Pages 设置页和 Actions 的部署结果中查看。

GitHub Pages 的网页可以通过网址访问。`noindex` 用于请求搜索引擎不收录，并不是访问密码。上传内容不包含原始聊天、临时截图、本地发布配置或离线压缩包。

## 修改

文字在 `dist/index.html`；好运签、互动与生日卡在 `dist/app.js`；样式在 `dist/styles.css`。资产放在 `dist/assets/`。原始聊天与本地参考资料不属于网站源代码，也不会被打包。
